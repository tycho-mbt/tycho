# rhi/sampler

Compares `Filter::Nearest` vs `Filter::Linear` on a 2x2 checkerboard texture using `@tycho`.

## Run

```bash
./build.sh
./_build/native/debug/build/laplaceliu/tycho_vulkan_examples/rhi/sampler/sampler.exe
```
