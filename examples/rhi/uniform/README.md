# rhi/uniform

Uniform buffer slot binding through `@tycho` (`CommandBuffer::bind_uniform`).

## Run

```bash
./build.sh
./_build/native/debug/build/laplaceliu/tycho_vulkan_examples/rhi/uniform/uniform.exe
```
