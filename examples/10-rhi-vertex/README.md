# 10-rhi-vertex

Vertex buffer input attributes (`Float2` position + `Float3` color) through `@tycho`.

## Run

```bash
./build.sh
./_build/native/debug/build/laplaceliu/tycho_vulkan_examples/10-rhi-vertex/10-rhi-vertex.exe
```
