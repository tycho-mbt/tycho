# 11-rhi-texture

Texture upload + sampler slot binding through `@tycho` (`Device::create_texture`, `CommandBuffer::bind_texture`).

## Run

```bash
./build.sh
./_build/native/debug/build/laplaceliu/tycho_vulkan_examples/11-rhi-texture/11-rhi-texture.exe
```
