# 22-descriptor-buffer

Example 22 — VK_EXT_descriptor_buffer: descriptors written into a buffer and

bound by offset instead of through descriptor sets. Seventh coverage batch.

## Windowing

This example runs headless (offscreen compute/graphics/API verification) and does not open a window.

## Run

```bash
./build.sh
./_build/native/debug/build/laplaceliu/tycho_vulkan_examples/22-descriptor-buffer/22-descriptor-buffer.exe
```
